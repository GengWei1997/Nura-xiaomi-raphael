# 小米 Redmi K20 Pro / Mi 9T Pro（xiaomi-raphael）

在小米 Redmi K20 Pro（SM8150 / 骁龙 855）上运行主线 Linux 的 Nura 软件包。

内核来自 [GengWei1997/linux](https://github.com/GengWei1997/linux) 的固定 commit，设备树是
`arch/arm64/boot/dts/qcom/sm8150-xiaomi-raphael.dts`，固件从手机自己的 vendor 分区提取。
